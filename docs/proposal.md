## Approach

A one-day, hands-on training session designed to equip journalists with practical skills in accessing government databases, analysing data, and creating publication-ready charts.

The session will target journalists at the beginner or intermediate level. No coding background required, although basic familiarity with data exploration tools such as Microsoft Excel or Google Sheets will be expected.

The approach can be adjusted based on a short pre-training survey to identify the participants' interests and technical skills.

Participants will also receive a post-training resource pack with slides, tools, links to guides, etc.

### Objectives

By the end of the session, participants should:

- Be able to find and navigate Moldovan government portals, as well as external open data repositories. We will also briefly cover some proprietary data sources that provide journalists with free information.
- Know how to clean, structure and analyse raw data, including with AI-assisted tools.
- Have a basic understanding of data visualisation, including what charts to use when. Participants will make their own charts using specialised tools such as Datawrapper.
- Learn good practices from data journalism projects published in Eastern Europe and across the world.

### Format

The training will be conducted over one day, 10:00-17:00. It will be conducted in Romanian, in person. Participants should bring their own laptops.

| Time | Session |
|-----------|------------------------------------|
| 10:00–10:30 | Welcome, introductions, and goals for the day |
| 10:30–11:30 | Using government and external databases |
| 11:30–12:30 | Data cleaning and structuring good practices |
| *12:30–13:30* | *Lunch break* |
| 13:30–14:30 | Data analysis and interpretation basics: common traps, how to spot the story in data |
| 14:30–15:30 | Data visualisation: what to (not) do and when |
| 15:30–16:30 | Group exercise: Draft a short topical story using real data |
| 16:30–17:00 | Q&A, further resources, discussions, wrap-up |
